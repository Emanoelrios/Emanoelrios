## Projetos e estudos práticos

Além das demandas profissionais, desenvolvo estudos para consolidar os fundamentos e conhecer outras formas de construir soluções SAP.

### Gestão de manutenção preventiva e corretiva

Projeto de estudo inspirado na minha experiência com refrigeração industrial. Inclui modelagem de dados no Dicionário de Dados, operações de cadastro e atualização, filtros e relatórios ALV. Também explorei CDS Views, SAP RAP e publicação de serviços OData no ambiente de aprendizagem.

### Relatórios ALV e ABAP Objects

Prática com ALV clássico e orientado a objetos, incluindo `CL_SALV_TABLE`, organização de colunas, filtros, seleção de registros e apresentação de dados para o usuário.

### Smart Forms e Module Pool

Exercícios de formulários, passagem de dados para impressão, telas e lógica de interação. Os estudos incluem o uso de BAPIs, como `BAPI_USER_GET_DETAIL`, e a separação do programa em componentes menores.

### Fundamentos ABAP

Estudos contínuos de tabelas internas, field symbols, loops, condições, Open SQL, modularização e debugging, com prática para entender e refazer as soluções.
